# 品質反復ログ (自己評価 → 改善サイクル)

「すべての要素が AAA レベルになるまで自己評価を繰り返す」ための開発記録。
評価基準はゲーム内の `QualityAudit.gd` と同一で、起動ごとにコンソールと
`user://quality_report.txt` に採点が出力される。

採点: **AAA = 90+ / AA = 75+ / A = 60+ / B = それ未満**

---

## Iteration 1 — 素組み (ベースライン)

| カテゴリ | 評価 | 問題点 |
|---|---|---|
| 建物 | B | 単色ボックスの群れ。夜に真っ暗で街に見えない |
| 質感 | B | StandardMaterial の単色のみ。路面がプラスチック |
| ライティング | B | DirectionalLight 1灯 + デフォルト環境。奥行きゼロ |
| 人間 | B | カプセル1本 |
| モンスター | B | 色違いの球。区別がつかない |
| カメラ | B | 固定カメラ |

**改善方針**: 実測データ (PLATEAU) と実写アセット (Poly Haven) のパイプラインを先に敷く。
見た目は「シェーダーで面を語らせる」方向に全振りする。

## Iteration 2 — データパイプラインとPBR

- PLATEAU CityGML → OBJ 変換器を実装 (LOD2 優先 / 外観テクスチャ UV 対応 /
  耳刈り三角形分割 / JGD2011→ローカルENU)。渋谷駅 700m 圏をメッシュコードで自動抽出。
- Poly Haven 公式 API から HDRI 3枚 / PBR 5セット / 樹木・岩 glTF を自動取得する
  `fetch_polyhaven.py` を実装。manifest.json で Godot 側と接続。
- 路面: アスファルト PBR + トリプラナー。建物: テクスチャ面はそのまま、無地面は仮マテリアル。

**残課題**: 夜景が死んでいる (窓が暗い)。雨の渋谷らしい「艶」が無い。

## Iteration 3 — シェーダーによる画作り

- `building_facade.gdshader`: ワールド座標窓グリッド + ランダム点灯 (暖色/寒色) +
  ちらつき + ビルごとの色調バリエーション。PLATEAU の無地 LOD2 面が夜のビルになった。
- `wet_road.gdshader`: fbm 水たまりマスク + 雨滴リップル法線 + 低ラフネス化。
  SSR と組み合わせてネオンが路面に映り込む。
- `neon_holo.gdshader` / `rift.gdshader`: グリフスクロール看板14枚 + 上空の次元の裂け目。
  OmniLight の照り返しをセットにして配置。
- 環境: HDRI IBL + SDFGI + SSR + SSAO + SSIL + ボリュメトリックフォグ + ACES + ブルーム
  + 雨パーティクル 6000 + リフレクションプローブ。

**残課題**: キャラクターが棒立ち。モンスターに個性が無い。

## Iteration 4 — キャラクターとシネマトグラフィ

- 人間: 関節階層パラメトリック人体 (SSS スキン / 布 / レザー / 異方性ヘア、目・眉・鼻まで造形)。
  手続きウォークサイクル (骨盤バウンス・膝の遊脚屈曲・腕逆位相・呼吸)。
  さらに `assets/characters/player.glb` を置くだけでフォトスキャン級モデルに差し替わる口を用意。
- モンスター5種: それぞれ専用シェーダー + 専用アニメーション
  (黒曜石マグマ / 玉虫色外殻 / ルーン石亀 / 半透明浮遊体 / 20m級怪獣の擬似SSS)。
  被弾フラッシュとディゾルブ消滅も全種対応。
- カメラ: 8ショット60秒 (クレーン→ドリー→トラッキング→ローアングル→ティルト→
  ワイド→プッシュイン→オービット+タイトル)。DoF をショット単位で制御。
  レターボックス + フェード + タイトルロゴ。

## Iteration 5 — 実画面レビュー (ソフトウェアGLレンダリングによる自己評価)

CI環境で Xvfb + llvmpipe (互換レンダラ) を使い、デモの8ショットを実際にPNG出力して目視レビュー。
`--screenshot=3,12,19,26,...` 引数を Main.gd に実装し、以後も同じ手順で回帰確認できる。

発見した問題と修正:

| 問題 | 修正 |
|---|---|
| 全窓が点灯し白飛び、街がディスコ状態 | 点灯率 45%→28%、発光 5.0→2.4、窓ごとの明るさムラ (0.25〜1.0) を追加 |
| 夜空フォールバックが漆黒で奥行きゼロ | 地平線に光害グラデーション (紫系) を追加 |
| 路面が見えず渋谷らしさが無い | スクランブル交差点の横断歩道 (十字+斜め)・車線・停止線をシェーダーで描画 |
| カゲオニのマグマ亀裂が多すぎて火の玉化 | リッジ閾値を絞り大域パッチマスクで疎らに (被覆 ~40%→~5%) |
| ゲンブが緑発光の塊 (カメラ寄りすぎ) | 発光 4.5→3.0、ショット6を8〜10m引きに |
| トシクイが遠すぎて見えない | 出現位置を 260m→175m に、プッシュイン終点を調整 |
| ストリートショットが上向きすぎ路面が映らない | 路面→裂け目へのティルトアップに変更 |
| タイトルと字幕が重なる | 字幕のアンカーを下げる |
| ヒーローショットの顔が真っ暗 | キー/リムの簡易2灯を54秒イベントで追加 |

再レンダリングの結果、夜景・戦闘・怪獣シルエット・タイトルの全ショットが成立することを確認済み
(修正前後の比較は PR のスクリーンショット参照)。

## Iteration 6 — ユーザーレビュー対応 (キャラ実モデル化 / 明度 / 建物・敵の作り込み)

ユーザーフィードバック「キャラが単純」「暗い」「建物・敵の作り込み不足」への対応。

**1. キャラクター → 既存の実3Dモデル + スケルタルアニメーション**
- `tools/fetch_characters.py` を新設。GitHub raw から Godette (Godot 公式 TPSデモ、
  約39,000頂点・4K PBR 4枚・55アニメーション・CC-BY 3.0) と Mannequiny (GDQuest・
  10アニメ・CC-BY 4.0) を自動取得。
- `CharacterRig.gd` 新設: モデル自動検出 (custom glb → Godette → Mannequiny → パラメトリック)、
  glTFの-Z正面を+Z規約へ正規化、身長正規化、ORMチャンネルパッキングを含む PBR マテイアル構築、
  "-cycle" 系アニメのループ化、モデル別アニメ名マッピング。
- Player はステートマシンで idle/walk/run (速度連動ケイデンス)・ジャンプ3段階 (踏切/滞空/着地)・
  攻撃 (2種交互) を再生。
- バグ修正: emission に白を設定すると加算で全身発光 → 黒 + テクスチャ加算に修正 (実画面レビューで発見)。

**2. 明度**
- 露出 1.1→1.4、月光 0.30→0.55、背景 0.8→1.05、SSAO 強度 2.0→1.4、
  明度補正 1.06、街灯 3.8/22m、ネオン照り返し 2.4/26m、地平線光害を強化。

**3. 建物**
- ジオメトリ: 基壇+タワー+セットバック+パラペット+室外機+ペントハウス+高架水槽+
  アンテナ/航空障害灯+屋上ビルボード+壁面縦看板のアーキタイプ生成 (1棟あたり6〜14パーツ)。
- ファサード v2: 3様式 (パンチ窓/カーテンウォール/リボン窓)、マリオン、床スラブ、雨だれ汚れ、
  1F店舗階 (大開口ガラス+店内光+看板色スピル)、御影石基壇。

**4. 敵 (全種 造形・質感・動きを増強)**
- カゲオニ: 55→約100パーツ (肋骨装甲・炉心+花弁・鎖枷・篭手・膝/肘/顎関節・爪先・踵スパイク) + 残り火
- ネオンリッパー: 首2節・可動顎+歯列・背ビレ5枚・ネオン管4本・尾5節+フィン・足首関節・鎌爪 + トレイル
- ゲンブ: 甲羅六角板14枚・回転ルーン環・頂部クリスタル・苔5箇所・縁スパイク8本・足首関節・尾2節 + 光の粒
- スクランブラー: 二重逆回転リング・コアケージ4本・軌道球3つ・触手8本×4節+先端クロー・膜スカート + 雫
- トシクイ: 前面装甲4段+炉心格子・側面装甲・角6本・歯列・背ビレ主列7+副列12・尾3節+スパイク・

- シェーダー: 黒曜石に微細法線+鉱物きらめき、玉虫色に装甲パネル継ぎ目 (擬似六角グリッド)。

実画面レビュー (第3〜4パス) で街並み・リッパー・店舗階の光を確認済み。

## Iteration 7 — 物語構成デモ / 白い四角の根治 / さらなる明度と建築ディテール

ユーザーフィードバック「白い四角」「物語性がない」「戦闘」「夜が暗い」「建築の作り込み」への対応。

**1. 白い四角の根治 (2段階のバグだった)**
- 段階1: 裂け目クアッドに横方向の境界フェードが無く、シェーダーで `ALBEDO` 未指定のため
  デフォルトの白(1,1,1)が加算合成で全面に乗っていた → 両軸エッジマスク + ALBEDO明示。
- 段階2: 修正後に裂け目が「完全に消える」→ 分離テストシーンで検証し、
  **互換レンダラは unshaded カスタムシェーダーの EMISSION を出力しない**ことを特定。
  unshaded では ALBEDO が最終色なので、rift / neon_holo を ALBEDO 出力に書き換え
  (Forward+ でも HDR 値の ALBEDO でグローが効く)。これでネオン看板群も互換環境で復活。

**2. 物語構成の60秒デモ (9ショット / 20イベント / 章テロップ8枚)**
「AM 2:47 渋谷、いつもの雨」→「空が、裂けた」(白閃光+裂け目誕生アニメ) →
「"それら"は街に降りた」(スポーンフラッシュでカゲオニ/リッパー出現) →
「迎え撃つ者、ただひとり」(疾走参戦) →「一体目、撃破」(3連撃→リッパーがディゾルブ消滅) →
「鬼との死闘」(鬼の振り下ろし/回避/反撃3発) →「だが、奴らは止まらない」(増援+巨獣接近) →
「それでも、渋谷を守る」(背中越しの決意ショット+タイトル)。
モンスターに demo_attack (攻撃モーション強制)、プレイヤーに疾走/向き指定/ポーズ再生APIを追加。

**3. 明度 第2弾**
露出 1.6 / 月光 0.85 / 背景 1.35 / 明度補正 1.12 / 窓点灯率 38% / 店舗階 5.2 /
被弾フラッシュを白→各モンスターの発光色 (白飛び解消)。

**4. 建築ディテール 第2弾**
- 形状: 円筒タワー / L字ツインタワー / コーナー付柱 / 高層クラウン照明 (4色) /
  エントランス庇+支柱 / 屋上手すり を追加
- ファサードv3: 窓ガラス1枚ごとの微傾き (反射がパネル単位でばらける) /
  室内光の天井グラデーション / 窓下の室外機シルエット / 窓下枠の落ち影
- 街路: ガードレール (支柱+ビーム) / 歩行者信号4隅 (赤・青) / 光る自販機8台

## Iteration 8 — アニメ再生の根本修正 / 戦闘の対峙 / 三倍体 / サウンド

ユーザーフィードバック「向きがおかしい」「歩いていない」「戦っているように見えない」
「パーツを動かして」「最後の敵を三倍体に」「音を素晴らしく」への対応。

**1. スケルタルアニメが一切再生されていなかった (根本原因の特定)**
- `--verbose` デバッグで `current_animation` が常に空であることを確認。
- 原因: **Godot の glTF インポータは "-cycle" サフィックスを剥がして自動ループ化する**
  ("Idle-cycle" → "Idle")。マッピングした名前が1つも実在せず、全モーションが不発だった。
- 修正: 実在チェック付きのアニメ名解決 (候補リスト+警告)。修正後のログで
  Idle / running_nogun / Idlecombat / 攻撃 / ジャンプ3段が正しく遷移することを確認。
  「歩いていない」「パーツが動かない」はこれで根治。

**2. 戦闘の対峙**
- `command_face_target(敵)`: 戦闘中は常に敵へ正対し続ける追尾フェイシング。
- 攻撃時は敵方向へ即時スナップ + 一歩踏み込み (velocity 加算) で「当てに行く」動き。
- `combat_mode`: 非移動時の基本姿勢が戦闘構え (Idlecombat) に。
- 間合い修正: リッパー戦 2.5m / カゲオニ戦 3〜4m (以前は6.9mの空振り距離だった)。
- 参戦ショットのカメラが近すぎて画面がプレイヤーで埋まっていた問題も修正。

**3. トシクイ三倍体 (20m級 → 60m級)**
- 造形3倍スケール + HP6000 / 射程20m / 歩速アップ。ショット8は 60m を見上げる
  ローアングルのプッシュインに再設計。ライト範囲140m、ストライドに震脚SFXを同期。

**4. サウンド (全編プロシージャル合成 → リポジトリ同梱)**
- `tools/generate_audio.py` (numpy): 60秒劇伴をデモのタイムラインに完全同期で作曲
  (Dマイナー/BPM128: 平穏パッド→8.0s裂け目braam→不穏パルス→20sバトルドラム+
  オスティナート→30.4s撃破クラッシュ→増援スネアロール→46s巨獣ハーフタイムbraam→
  52s決意の壮大進行 Bb–F–C–Dm + ホーン)。
- フリープレイ用32秒ループ、雨環境音 (シームレスループ)、SFX 9種
  (斬撃/ヒット/スポーン/裂け目/消滅/カゲオニ咆哮/リッパー金切り声/トシクイ咆哮/巨獣足音)。
- `AudioKit.gd`: ogg/wav 自動解決・3D位置SFX・ループBGM。ゲーム内は被弾/攻撃/死亡/
  足音が自動発音。Movie Maker は音声もAVIに記録し、MP4 に AAC 192k で同梱。

## Iteration 9 — 前後逆の根治 / 戦闘の可読性 / 街の美化 / 動きの精密化

ユーザーフィードバック「走る主人公が前後逆」「戦闘がわかりにくい」「町をもっと美しく」
「ロボットの動きも精密に」への対応。

**1. 前後逆の根治 (検証ベース)**
- 素のglbを±Z両側からレンダリングして検証: **Godette の正面は +Z (glTF規約通り)**。
  以前の「-Z正面」推定に基づく180°ラッパーが逆走の原因だった → 回転を0に修正。
  修正後のレンダで、フェイスプレート・胸エンブレムを進行方向に向けて走ることを確認。

**2. 戦闘の可読性**
- 被弾時: 白熱の衝撃スパーク (膨張+ライト) + 打撃方向へのノックバック + 仰け反りリコイル
- カメラシェイク: 斬撃/鬼の振り下ろし/裂け目誕生で衝撃、46秒以降は巨獣接近の地響き微振動
- スラッシュVFXを大型化 (3.2m) + 拡大アニメ追加

**3. 街の美化**
- 遠景スカイライン110棟 (半径300〜800m、時々超高層) — 空虚だった地平線が都市の海に
- 街灯12基に光芒コーン (フェイクボリュームライト、light_shaft.gdshader) — 雨夜の代名詞的表現
- ネオンビルボード14→20枚、屋上ビルボード/縦看板の出現率アップ、空のグラデーションを低く濃く

**4. 動きの精密化**
- 旋回バンク: ヨー角速度に応じて body が内側に傾く
- 向き平滑化をフレームレート非依存 (1-exp(-k·dt)) に統一
- 攻撃時の敵方向スナップ+踏み込みは前回実装済み → ノックバックと合わせ打撃が「通る」

## 継続的な自己評価の回し方

1. `setup_windows.bat` でアセット取得 → Godot で F5 → コンソールの監査表を見る
2. 90 未満の行に対して上表の「条件」を満たす
3. `py -3 tools\make_demo_mp4.py` で60秒MP4を出力し、目視レビュー
4. 気になったショットは `DemoDirector.gd` の `_build_shots()` の座標を調整して再出力
